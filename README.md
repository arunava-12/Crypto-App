# 💰 Crypto Marketplace

A modern and responsive crypto marketplace web application that displays trending cryptocurrency coins, NFTs, market data, and categorized tabs for assets, exchanges, categories, and holders. Built using HTML, CSS, JavaScript, and Chart.js, this project utilizes real-time data from APIs to help users stay informed about the crypto world.

## 🔍 Features

- 🪙 **Trending Coins & NFTs**: View the latest trending cryptocurrencies and NFT projects.
- 📊 **Live Market Data**: Display real-time global stats like market cap, 24H volume, BTC/ETH dominance, and more.
- 🧭 **Multi-tab Navigation**:
  - **Assets**: Explore a wide range of listed assets.
  - **Exchanges**: Discover popular exchange platforms.
  - **Categories**: Browse coins by categories.
  - **Holders**: View company or institutional holders.
- 🔎 **Search Functionality**: Quickly search and locate specific assets.
- 🌗 **Theme Toggle**: Switch between light and dark modes.
- 📱 **Responsive Design**: Mobile-first approach ensures usability across all devices.
- 🔗 **Social Integration**: Links to GitHub, LinkedIn, and Instagram included.
